# ShopEase – Single Page Application (SPA) Simulation

## 📌 Project Overview

ShopEase is an e-commerce website enhanced with a simple Single Page Application (SPA) simulation using HTML, CSS, and JavaScript. The project demonstrates client-side navigation, dynamic content display, and URL management without requiring a full page reload for each navigation action.

## 🎯 Objectives

- Understand the basic concept of SPA architecture.
- Implement client-side routing using JavaScript.
- Display different website sections dynamically.
- Update the URL using the browser History API.
- Support browser Back and Forward navigation.
- Preserve the existing website design and functionality.

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and responsive layout
- **JavaScript** – Dynamic content and routing
- **History API** – Browser URL and navigation management

## ✨ Features

- Home section
- Product categories section
- Featured products section
- Customer reviews section
- Navigation without full page reloads
- URL hash updates
- Browser Back and Forward support
- Existing product search and shopping cart functionality

## ⚙️ How to Run

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Ensure that `index.html`, `style.css`, and `script.js` are in the same folder.
4. Open `index.html` in your browser, or use the Live Server extension.
5. Click Home, Categories, Products, and Reviews to explore the navigation.

## 🔄 How It Works

1. JavaScript reads the current URL hash.
2. The selected section is displayed dynamically.
3. Other sections are hidden.
4. The History API updates the URL without reloading the page.
5. The `popstate` event handles browser Back and Forward navigation.
